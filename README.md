## 论文交付与二轮完善

主成果是按学校要求形成的完整正式论文DOCX，包含全部适用篇章、分析、图表、引用与必要附录。材料补充、修订动作及质量检查独立整理。

收到独立说明后，直接回传当前论文、对应说明、新增资料及本轮意见，进入 [二轮完善](mba-thesis-writer/references/delivery-contract.md#补充资料后的二轮完善)。技能以用户最新主稿接续，核验并整合资料，重做受影响分析，同步方法、图表、讨论、方案、引用及中英文摘要和结论，完成自然化、去重及Word复核后交付新版完整论文和更新后的独立说明。支持分批补料，并根据实际处理结果更新任务。

> 使用mba-thesis-writer，按二轮完善路径，将当前论文、独立说明和新增资料整合成新版完整论文。保留我的已认可修改，据新证据更新分析与结论，完成关联内容和Word复核；独立说明写清实际处理结果、新位置与复核情况。

## 结构与规范

沿用精简结构：31个包体文件、12份专题参考、7个可选工具。研究设计、可靠来源、现行国标引用、图表、自然化与去重、可编辑Word及逐页验收按任务读取。引用基线为GB/T 7714-2025，学校格式采用当期模板。

仓库文件区仅保留当前最终版。实际检查与本轮试用范围见本版复核说明。学校模板及MBA要求沿用原发布方适用条件；仓库尚未指定统一开源许可证。
