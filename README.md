# MBA Thesis Writer

MBA 专业学位论文研究、写作、证据核验、图表生成和 Word 定稿技能。

基线版本：`1.0.0`

## 内容

- `mba-thesis-writer/`：完整技能目录，入口为 `SKILL.md`
- `mba-thesis-writer-1.0.0-baseline.zip`：可直接分发的安装包
- `mba-thesis-writer-1.0.0-baseline.zip.sha256`：安装包校验值
- `MBA论文Skill基线版说明.md`：验证范围、限制和维护说明

## 使用

支持技能发现的 agent/harness 按其本地技能安装机制加载 `mba-thesis-writer/`。不能自动发现技能的环境，直接读取该目录的 `SKILL.md`，并按其中链接的参考文件执行。通用安装、路径约定、可选 Python 工具和降级方式见 [技能安装说明](mba-thesis-writer/README.md)。

技能不依赖特定模型、供应商、原开题技能、历史对话或连接器。引用格式按项目启动与定稿时核验最新现行中国国家标准；当前基线记录为 GB/T 7714-2025。

## 许可与资料边界

本仓库用于保存用户指定的技能基线。随包的学校模板和论文要求文件来自用户提供的资料，使用时应遵守其发布单位和适用范围；未经确认不要将这些文件当作通用学校规范。研究成果和企业内部资料不包含在本仓库中。
