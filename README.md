# MBA Thesis Writer

以完整MBA学术论文为主成果的独立研究、分析、写作与Word交付技能。支持从题目、已通过开题、已有稿和导师意见启动，连续完成研究、全部章节、图表、引用和内部复核。

当前最终版：`1.4.0`。仓库文件区仅保留此版本，直接使用下方安装包或完整技能目录。

## 核心能力

| 研究阶段 | 主要工作 |
|---|---|
| 研究设计 | 继承开题，由文献形成分析框架，明确关键概念、指标、方法与章节 |
| 证据与文献 | 主动检索可靠资料，筛选第三方数据，核验来源与论断支持 |
| 调查与分析 | 问卷和访谈设计、实际记录清洗与分析、明确假设的情景分析 |
| 方案形成 | 问题诊断、机制与文献讨论、备选取舍、实施评价及管理贡献 |
| 成稿与交付 | 写齐完整学术论文，制作图表，完成学术表达自然化与全文去重，复核引用与一致性，按模板输出Word并检查页面 |

研究逻辑和目录按具体选题设计，覆盖营销、战略、财务、人力、运营、供应链、数字化等MBA方向。正文采用完整正式论述；实质补充事项另交付独立说明，写清内容、位置和修改方法。数据与方法据实说明，生成数据用于其方法中明确的情景分析。完整交付要求见 [成品交付要求](mba-thesis-writer/references/delivery-contract.md)。

## 通用使用方式

本技能不依赖特定模型、原开题技能、历史对话或连接器。支持技能发现的agent/harness按其安装机制加载整个`mba-thesis-writer/`目录；其他环境把完整目录放入可读工作区，读取`SKILL.md`并按链接加载参考资源。Python工具可选，完整Word交付由环境可用的文档与排版工具完成。

让AI下载并使用时可复制：

> 请从 https://github.com/xjx19960516/mba-thesis-writer 下载当前最终版完整技能，读取baseline.json确认版本，并核对相应安装包及SHA256。保留全部文件和隐藏资源，先读README.md与SKILL.md。按当前环境机制安装，或放入可读工作区直接执行；保留已有本地修改。有Python时运行scripts/doctor.py --self-test，报告版本、位置和实际自检结果。我的论文任务是：【填写任务】；论文资料与输出目录是：【填写目录】。请完成完整论文和内部复核，补充事项单列准确位置与处理方法。

仓库下载包中的技能位于内层`mba-thesis-writer/`；版本安装包解压后同名目录就是技能根目录，以同时包含`SKILL.md`、`baseline.json`和`manifest.json`确认。

## 规范与验证

引用按项目启动和定稿时核验的最新现行中国国家标准执行。随包引用基线是2026-10-10核验的GB/T 7714-2025。内置全国MBA论文要求、中科大模板及参数；其他学校按其当期模板调整。

1.4.0通过入口格式、资源链接、安装自检和包体一致性检查；本轮加强研究框架、指标操作化、结果讨论与管理贡献，并修复答案登记和章节覆盖细节；99项回归检查全部通过，独立内容复核与安装自检通过。Windows为实测平台；完整论文的研究内容与实际分页按每个项目复核。详细执行范围见本版验证记录。
