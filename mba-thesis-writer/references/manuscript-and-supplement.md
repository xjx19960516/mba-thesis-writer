# 论文正文与独立补充说明

完整论文以逻辑严谨、篇章完整、调查与证据充分、理论应用恰当、方案可执行为交付目标。先完成可以自行处理的研究和修改，再把确需补证、用户材料或决策的事项集中写入独立说明。

## 论文正文

正文按学术论文组织问题、证据、分析、解释、方案与结论。删除“未完成”“后续补充”“需要整理”“尚未体现”“此处插入”等编辑指令、流程汇报和占位句，写成可连续阅读的实质段落。此要求针对流程性用法；真实研究对象的状态或有实质内容的研究展望依原意保留。

每章围绕明确问题形成证据和判断，图表在正文得到解释，重要结论回应研究问题。核对调查对象、研究期间、工具、实际取得过程、样本/资料覆盖、分析过程和来源定位，使“调查充分”由材料和方法支撑。

数据性质用简洁的学术方式表达：真实问卷写实际对象、回收记录和分析方法；公开数据写来源与口径；情景分析写参数、生成方法和假设。图表来源与方法保持一致，避免在各段重复流程提醒。模拟结果不能表述成已完成的真实问卷调查；独立补充说明也不替代正文必要的数据来源说明。

编辑性事项全部移出正文。样本范围、测量误差、识别条件、适用情境等影响结论理解的研究局限，用具体、克制的学术语言写在相应方法、讨论或结论位置。避免泛化免责声明和与研究无关的边界强调。

## 内容如何分配

| 内容 | 落点与写法 |
|---|---|
| 缺项、替换计划、材料索取、编辑进度、工具或版式检查待办 | 全部写入独立说明，主稿不保留任务编号、占位句和重复提醒 |
| 泛化自评，如“研究不够深入”“资料仍需完善” | 先定位并修复实际问题；确需材料的动作写入独立说明，正文不保留空泛自评 |
| 数据来源、实测或生成性质、样本与方法 | 在方法或来源处简洁交代，后文按该方法解释结果，独立说明可记录更详细的来源与替换步骤 |
| 影响结论含义的适用条件、抽样范围、识别条件 | 在相关论述中具体表达；学校要求的研究局限栏目按实际内容填写 |

方法说明不采用“警告”“仅供参考”或逐段重复的数据提醒。生成问卷数据的可用写法为：“本节采用按设定参数生成的模拟问卷数据进行情景分析，变量定义和生成规则见……。”图表来源可写“依据第X节所述模拟数据计算”，实际引用替换为对应位置。关键是单独阅读主稿仍能理解数据性质，不能只在额外文档披露或把生成样本写成真实回收答卷。

独立说明承接具体行动，例如：“取得与问卷V2对应的真实答卷，按代码本清洗；重算第4.2节表4-2至表4-4；更新第4.3节机制解释、第5.1节方案排序和中英文摘要的样本与结论。”这些位置仅为结构示例，交付时逐项替换为主稿的实际锚点。

## 独立补充说明

有实质补充项时另交付《论文补充材料与修订说明》，默认提供可编辑DOCX；用户指定其他格式时按要求。该文档与论文分别保存，不并入论文正文、附录或目录。格式结构可参考 [补充说明模板](../assets/revision-notes-template.md)。

先记录对应论文题名、文件名、内容版本和核对日期，按任务ID逐项说明：

| 信息 | 具体写法 |
|---|---|
| 当前依据 | 当前采用的数据/材料性质、来源文件与版本、生成或分析参数位置，是否已经核验 |
| 补什么 | 实际资料、字段、期间、口径、样本/对象及所需形式 |
| 补在哪里 | 章/节标题、段落首句或短摘录、表图编号、相关摘要或结论位置 |
| 如何补 | 取得渠道、调查或访谈步骤、清洗/计算方法和正文修改动作 |
| 影响什么 | 受影响的判断、图表、原因解释、措施及中英文摘要 |
| 如何验收 | 可检查的完成条件和需重做的质量核对 |

页码是辅助定位；换页后仍以标题、段落锚点及稳定ID定位。把数据缺口、导师待决项、格式待确认和可选优化分别说明，明确优先级及责任。对可以联网取得、计算修复或直接润色的内容，先实施，再只保留确需后续动作的事项。没有实质补充项时无需生成空清单。

## 与项目记录及更新同步

复用project.json的tasks[]和稳定数据/论断ID。可在任务中保存`draft_locations`、`required_inputs`、`replacement_rule`、`acceptance_criteria`和受影响ID；新增内容是定位记录，项目审计只核对其支持的状态字段。补充说明是给用户阅读的整理版，不复制全部内部日志。

真实资料到达后逐项取得、核验和分析，修改正文及所有关联结果，在补充说明中记录处理及复核结论。更新稿件版本和定位后关闭任务；正文交付前完成流程性语言检查。含临时结果时，文件名及独立说明体现研究稿状态，正文保留必要的方法与来源表达，按 [临时工作稿](temporary-results-workflow.md)管理数据替换。
