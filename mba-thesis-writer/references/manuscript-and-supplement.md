# 正式论文正文与独立修订说明

论文是完整、正式的学术成果。写作围绕对象事实、文献、方法、证据、发现、解释和管理成果展开；可以自行取得的资料、可以完成的分析与修改先落实到主稿。

## 正文内容

每章提出具体研究任务，展开相连论证，图表用于支持比较和解释，章末收敛已建立的判断。摘要与结论概括实际研究成果，正文各部分采用正式学术语体。

| 内容 | 处理方式 |
|---|---|
| 对象、期间、资料/样本、指标、方法和数据来源 | 在方法或图表来源等适当位置准确交代，后文据此分析 |
| 抽样范围、测量、识别和适用情境 | 用具体研究事实表达对结论的影响；学校要求的栏目按实际研究内容完成 |
| 材料取得、替换步骤、导师待决项和编辑进度 | 整理成独立修订说明，并定位到主稿实际位置 |
| 工具输出、重复命中、排版检查和版本记录 | 留在项目或检查文件，完成处理后修订主稿 |
| 泛化质量自评、免责声明、对话回应和占位句 | 回到对应问题补实质内容或精确改写，主稿形成正式论述 |

例如，“本研究不够深入，资料仍需补充”应落实为具体分析或取证动作，完成后写出研究判断；“仅供参考”“因能力有限”“后续再整理”“此处插入”等不承担论文论证职能。研究对象本身的未完成事件或有实质内容的展望依原意叙述。编辑状态也不写入页眉页脚、题注、摘要、结论或附录。

## 方法与来源的学术写法

真实调查交代实际对象、工具、期间、取得过程和有效样本；公开资料写发布主体、期间及指标口径；情景研究写参数依据、生成方法和假设。论文独立阅读时，读者能据此理解结果的性质和含义。

来源说明在方法和必要题注中完整、简洁表达，后续分析承接该说明。例如，情景研究可写“依据业务规则设定参数构建情景样本，并按第X节的方法比较方案表现”；图表来源写“依据第X节所述情景样本计算”。临时模拟问卷使用“模拟问卷数据”及对应方法定位，真实回收记录按实际调查填写。

讨论以具体条件解释发现，如“样本覆盖该业务单元2025年的在册客户，分组比较采用相同复购窗口”。研究条件用于解释结果，编辑性待办由独立文档承接。

用实际采用的方法和指标自然界定推断目标，例如“采用月度汇总记录进行存量核算和描述比较”。集中说明影响结论理解的条件，后续段落直接展开对应分析；无关资料缺项和未采用模型无需逐项列举。摘要与结论聚焦做了什么、发现了什么、形成何种贡献，用“同期变化”“建议目标”“情景测算”等准确用语表达结果性质，避免反复追加“无法证明”“尚无支持”“不代表效果”等尾句。

区分研究发现与写作状态：不显著、相反或无效的主要结果属于论文内容，按实际报告；工具能力、作者能力自评及补稿进度留在论文之外。必要的研究条件在相应方法或讨论中讲清，不将每段写成能力或证据边界说明。

## 独立修订说明

有实质修订事项时另交付《论文补充材料与修订说明》，默认可编辑DOCX；用户指定其他格式时按要求。该文档与论文分别保存，可用 [说明模板](../assets/revision-notes-template.md)，不并入论文目录或附录。

记录对应题名、论文文件、内容版本和日期，复用项目中的稳定任务ID：

| 信息 | 具体要求 |
|---|---|
| 当前依据 | 已采用材料、性质、来源/版本及实际分析依据 |
| 补什么 | 具体资料、字段、期间、口径、对象及所需形式 |
| 在哪里 | 章/节标题、段落锚点、表图编号及关联摘要/结论位置 |
| 如何补 | 取得渠道、调查步骤、清洗/计算与正文修改动作 |
| 联动与验收 | 受影响的判断、图表、解释、成果，以及可检查的完成条件 |

页码作为辅助定位。先完成能够检索、计算或直接修订的内容，说明只保留确需用户资料或决定的实质事项，不生成空清单或复制全部日志。来源与替换详情在独立文档中展开，论文保留理解研究所需的方法和来源。

资料到达后核验、分析，并用稳定ID更新正文、图表、解释、成果、摘要和结论；完成返修及关联复核后更新记录和稿件位置，关闭对应任务。先试写后补实测的特殊任务另按 [临时工作稿](temporary-results-workflow.md)执行。
