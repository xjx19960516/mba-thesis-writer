# 完整论文成品交付要求

完整论文任务以一个可连续阅读、可编辑、研究过程可复核的完整DOCX为主成果。持续完成实质写作、分析、内部返修和版式检查；任务进度保存在项目记录中，最终正文采用正式学术表达。

## 交付前逐项落实

| 项目 | 成品中的实际落点 |
|---|---|
| 篇章完整 | 全部适用前后置内容、正文、参考文献和必要附录；各章具有实质分析和结论 |
| 研究闭环 | 每个研究问题都有证据、方法、分析判断和对应实践成果，摘要与结论忠实概括 |
| 调查充分 | 实际研究对象、资料/样本、取得过程、分析及来源可追溯，覆盖支持论文推断的范围 |
| 方案可用 | 成因与措施对应，备选取舍、责任、资源、时间、约束和评价指标具体 |
| 图表一致 | 数值可复算，分母、单位、期间和来源明确，编号、标题与正文引用一致 |
| 引用准确 | 所引内容支持论断，正文和文后列表双向对应，按本次核验的现行国标及学校格式处理 |
| 表达完整 | 清理编辑指令、空白占位、机械重复和空泛免责声明；保留具体方法、来源与解释条件 |
| 文件可用 | 可编辑Word，目录及字段更新，实际渲染并逐页复核，附件与主稿版本对应 |

先修复可自主处理的问题，再形成交付说明。自动检查配合实际来源与内容审读；核对范围和结果记录在质检说明中。

## 调查材料按研究需要完成

缺问卷时，根据研究问题与理论构念生成可实际使用的完整问卷，包含调查说明、适用对象、题项、量表/选项、变量编码及必要跳转逻辑，并准备回收与分析方案。访谈提纲、观察记录表、数据字典和报告结构采用相同方式补齐。量表引自文献时核对来源、适配及使用条件。

缺分析报告但有真实记录时，实际清洗、计算并生成报告、图表及论文段落。外部背景或行业数据不足时，主动检索可靠来源并核验后纳入。

缺真实答卷时，预期结论转为可检验假设。可用明确参数生成情景数据及完整分析报告，用于方法演示、方案比较或论文结构安排；方法与图表来源说明生成性质和假设，正文不虚写发放、回收、受访者或已发生的实施效果。真实记录的结果决定最后的经验判断。生成工具支持范围见 [问卷生成工具](survey-simulator.md)，其范围之外的题型或分析由适合的工具实际执行。

按真实研究目标和现有证据选择可执行路径；需要改变已通过开题的核心方法时，按现有授权推进，必要决定集中提出。以模拟方法作为正式研究时，研究问题、参数依据、验证和解释范围均应匹配该方法；临时替代真实调查的内容按 [更新流程](temporary-results-workflow.md)管理。

## 主稿与独立说明同步

主稿写成完整篇章，操作待办统一放入 [独立补充说明](manuscript-and-supplement.md)。每项具体列出材料、取得步骤、章/节标题、段落锚点、表图编号、计算与修改动作、受影响摘要/结论以及验收条件；同时交付已经能够完成的问卷、提纲或分析材料，减少用户从零整理的工作。

数据与方法的必要说明保留在论文相应位置。补充说明记录编辑动作，方法章说明研究实际，两者各自清楚完整。完整研究稿与已完成取证和复核的送审候选稿在文件名和交付说明中准确区分，保持正文正式连贯。

每次材料更新后联动重算图表，修订解释、成因、方案、摘要和结论，重新核对受影响的引用与分页，更新独立说明中的位置与处理结果。以当前版本的实际研究和检查记录判断交付完成。
