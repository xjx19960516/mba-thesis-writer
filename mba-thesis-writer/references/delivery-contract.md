# 完整MBA学术论文的成品要求

完整论文任务的主成果是一篇可连续阅读、可编辑、研究过程可复核的正式MBA学术论文DOCX。持续完成研究、实质写作、内部返修与Word定稿，各章承担明确的研究职能。

## 成稿核对

| 项目 | 论文中的实际落点 |
|---|---|
| 篇章完整 | 中英文题名/摘要/关键词、绪论、文献与框架、方法、结果与讨论、管理成果、结论、参考文献及学校适用的前后置内容和必要附录 |
| 研究闭环 | 研究问题有实际答案、分析位置与证据；理论框架参与分析，摘要和结论概括同一组成果 |
| 调查与分析 | 对象、资料或样本、取得过程、指标/编码、分析与来源可追溯，证据覆盖研究目标 |
| 成果成立 | 专题/决策型研究形成有依据的措施、备选取舍及实施评价；描述型案例形成事件与理论支持的机制解释、实践认识及适用情境 |
| 图表准确 | 数值可复算，口径、单位、期间和来源明确，图表与正文解释一致，数值表可编辑 |
| 引用规范 | 实际内容支持所引观点，正文与文后双向对应，采用本次核验的现行国标及学校格式 |
| 表达成熟 | 完成学术表达自然化、全文去重及关联回校，正式语体、稳定术语、相连论证，篇幅符合学校口径 |
| 文件完备 | 一个完整DOCX，目录与交叉引用更新，全部页面完成实际检查，研究附件对应本稿 |

按研究目标判断完成：发现回答了什么，解释如何成立，贡献新增了什么，管理成果如何使用。核对发现的问题先返修，随后按当前稿件重新检查受影响内容。

## 正文及配套材料

正文按 [正文与独立说明](manuscript-and-supplement.md)呈现研究内容。写作计划、补充材料动作、工具结果和检查进度分别保存在项目文件，学校要求的声明按模板位置填写。

研究附件整理实际使用的调查工具、证据/文献索引、数据字典和必要计算材料；与论证密切相关的工具或补充分析按需要进入附录。存在确需用户资料或决定的修订事项时，单独交付《论文补充材料与修订说明》，逐项说明补什么、准确位置、如何补及关联修改。能够主动检索、分析和修复的内容先完成；无实质事项时直接交付论文及必要附件。

## 调查与材料更新

需要调查工具或数据分析时，按 [问卷与结果分析](questionnaire-and-simulation.md)完成问卷、代码本、取得方案、实际清洗计算及正文整合；外部资料按 [证据筛选](evidence-and-citations.md)主动补齐。资料更新后同步修订分析、图表、方案或案例解释、摘要及结论。

论文研究与用户已通过的核心设计保持一致；数据路径或方法需要实质调整时，形成可执行方案并按已有授权推进。用户明确委托先试写后补实测时，采用 [临时工作稿流程](temporary-results-workflow.md)，在独立记录中管理替换。项目阶段、实际研究进度与稿件检查范围按 [项目记录](project-schema.md)维护。
