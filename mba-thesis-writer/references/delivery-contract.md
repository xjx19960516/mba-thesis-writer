# 论文交付与正文规范

主成果是一篇完整、正式、可连续阅读的MBA学术论文DOCX。完成研究、全文、内部返修及实际排版验收，按下列内容核对成稿。

## 成稿核对

| 项目 | 成品中的实际落点 |
|---|---|
| 篇章完整 | 中英文题名/摘要/关键词、绪论、文献与框架、方法、结果与讨论、管理成果、结论、文献及学校适用的前后置内容和必要附录 |
| 研究闭环 | 问题有实际答案、分析位置和证据；框架参与分析，摘要和结论概括同一组成果 |
| 调查与分析 | 对象、资料/样本、取得过程、指标或编码、分析及来源可追溯，覆盖研究目标 |
| 成果成立 | 专题/决策型形成有依据的措施、备选取舍、资源安排及实施评价；描述型形成事件与理论支持的机制解释和实践认识 |
| 图表准确 | 数值可复算，口径、单位、期间、来源和正文解释一致，数值表可编辑 |
| 引用规范 | 实际内容支持所引观点，正文与文后双向对应，使用现行国标及学校格式 |
| 表达成熟 | 完成自然化与去重、关联回校及篇幅核对，稳定术语和完整解释链 |
| 文件完备 | 一个完整Word，目录及交叉引用更新，全部页面实际检查，附件对应本稿 |

## 正文与独立说明

正文用正式学术论述呈现问题、证据、方法、发现、解释和管理成果。材料索取、替换动作、编辑进度及工具记录分别保存；先完成能够自主检索、分析和修订的问题。

| 内容 | 放置方式 |
|---|---|
| 对象、期间、资料/样本、指标和取得过程 | 方法章及相关图表来源，按实际研究准确交代 |
| 抽样、测量、识别和适用情境 | 相应方法或讨论中的具体研究条件，按学校适用栏目完成 |
| 材料取得、替换步骤及导师待决项 | 独立修订说明，定位到主稿实际位置 |
| 重复命中、排版检查及版本 | 独立项目/检查记录，主稿呈现处理后的论述 |
| 泛化自评、免责声明、对话回应及占位句 | 回到实际问题补分析或精确改写，形成正式研究内容 |

“仅供参考”“因能力有限”“后续再整理”“此处插入”等不承担研究论证职能；研究对象本身的未完成事件或有实质内容的展望按原意叙述。编辑状态也不写入摘要、结论、题注、页眉页脚或附录。

### 方法与来源的学术写法

真实调查写实际对象、工具、期间、取得过程和有效样本；公开资料写主体、期间及口径；情景研究写参数依据、生成方法和假设。方法和必要来源简洁完整，后文承接该说明。模拟问卷使用“模拟问卷数据”及方法定位，真实回收记录按实际调查填写。

例如，“采用月度汇总记录进行存量核算和描述比较”自然界定了方法与推断目标。集中说明影响结论理解的条件，再展开对应分析，无关缺项和未采用模型无需逐项列举。摘要与结论聚焦做法、发现和贡献，用“同期变化”“建议目标”“情景测算”等准确表达性质，避免反复追加“无法证明”“尚无支持”等尾句。相反、不显著或无效的主要结果属于研究发现，按实际完整呈现。

## 文件与修订

论文按学校模板完成适用声明、匿名/归档版本及附录。研究附件整理实际使用的工具、证据/文献索引、数据字典和计算；与论证直接相关的工具及补充分析可放论文附录。精简检查记录保留实际输入稿件、范围和结果。

有确需用户材料或决定的事项时，另交付《论文补充材料与修订说明》，默认DOCX，可用 [说明模板](../assets/revision-notes-template.md)。与论文分别保存，不并入论文目录或附录；无实质事项时不生成空清单。

说明记录题名、文件、内容版本和日期，复用稳定任务ID，逐项写明：当前材料/性质及来源；补什么字段、期间与口径；在哪里修改（章/节、段落锚点、表图及摘要/结论）；如何取得、清洗计算和替换；关联影响及验收条件。页码作为辅助定位。

资料更新后联动分析、图表、解释、成果及摘要/结论，返修与复核完成后更新记录、位置及任务。长期管理见 [项目记录](project-schema.md)，先试写后补实测见 [问卷结果更新](questionnaire-and-simulation.md#临时结果与真实数据更新)。

## 补充资料后的二轮完善

输入当前论文、对应的独立说明、新增资料及本轮意见，直接接续整合与定稿。同一会话已有文件直接沿用；有项目记录时一并读取，没有记录也可按实际文件开展。资料可一次或分批提供，无需重新开题或重做已完成研究。

1. **接续最新主稿**：核对文件、版本与说明的对应关系，保存原稿。以用户最新修改稿为基稿，保留已认可修改，将旧说明中的章/节、段落和表图定位映射到当前正文；无法判断的关键版本冲突集中核实。
2. **匹配与核验资料**：按任务ID或资料内容关联补充事项，核验来源、期间、口径及覆盖范围。先判定追加记录、更正原值或整批替换，按记录标识与期间核对重叠、重复及冲突，确定本轮实际样本与分析范围；保留原始文件和采用依据。先整合本次已经满足的部分，其余事项保留在独立说明并更新所需内容。
3. **重做相关分析**：用新材料完成清洗、计算、编码或证据综合，保留分析依据。汇总资料按其实际信息分析。新证据改变原判断时据实更新发现、解释及方案；题目、核心方法等研究基线的实质变更沿用既有授权规则。
4. **整合全部关联位置**：同步方法与样本说明、结果、图表及来源、讨论与成因、管理成果、引用和附录，再回校中英文摘要与结论。只调整受影响内容并处理必要衔接，不覆盖无关的用户修改。
5. **复核与Word定稿**：完成表达自然化、去重、数字、论证及引用一致性检查，更新内容版本和受影响QA。按 [成稿核对](#成稿核对)装配新的完整DOCX，更新目录、题注、交叉引用与页码，按 [Word逐页验收](word-and-tables.md#全文定稿与逐页验收)检查全部页面；以该文件对应的实际检查确定定稿状态。
6. **交付与关闭事项**：交付新版完整论文及更新后的独立说明、精简复核记录。说明逐项记录采用的材料、实际修改、新位置及核验结果；材料核验、分析更新、正文整合和关联复核完成后才关闭任务。尚需材料的事项继续明确列在独立说明，不混入正文。旧稿及旧分析保留在项目历史中，交付位置明确本次采用的版本。

后续补料继续使用同一路径，任务ID沿用，位置与检查记录对应最新论文。问卷临时结果替换同时执行 [问卷结果更新](questionnaire-and-simulation.md#临时结果与真实数据更新)，不以资料上传代替实际分析和整合。
