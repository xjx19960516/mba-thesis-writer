# 写作与质量复核

## 形成有研究内容的全文

遵循 [正文与补充说明](manuscript-and-supplement.md)：正文采用正式学术表达，删除流程性占位和编辑指令，实质补充项另行形成文档并定位。按该参考的内容分配表处理材料补充、空泛自评、方法说明和实际适用条件，保持全文措辞一致。

章节写作先明确问题、证据和该章贡献，再形成相连的分析段落。核心章节应包含具体事实、比较、解释机制、备选解释与管理含义。绪论从真实背景落到研究对象和问题；综述说明共识/分歧/适用情境及本研究位置；结论逐一回答研究问题，只概括已得结果；摘要最后写，确保对象、方法、样本、数字和结论一致。

用对象特异性复核：替换企业名称后，分析是否仍几乎原样成立？若是，回到业务流程、资源约束、数据、事件、决策与组织机制补深，不用机械同义词替换制造差异。篇幅服务证据与论证；不重复背景、图表数字或章末总结来凑字数。

## 结果、讨论与结论

结果陈述实际发现，围绕研究问题选择关键比较、数量关系或主题证据；讨论解释发现如何回答问题、与已有研究的关系及情境原因，并说明其管理含义。两者可在同章组织，也可分章，段落职能保持清晰。图表附近文字提炼发现，讨论增加解释和文献对话。

涉及统计检验时，完整报告核心研究问题对应的主要比较或检验，包括不显著和与预期相反的结果。区分事先提出的检验与分析中形成的探索，多重比较按实际方法处理；根据同批资料形成的新解释作为探索性认识讨论。

核心论证按“判断—证据—推理—管理含义”组织：先提出本段要说明的判断，给出可定位的数量关系或事件证据，再解释证据如何支持判断以及与研究框架的关系，最后连接适当的管理决策。按论证需要分成相连段落，不把它写成每段固定四句的模板。引用支持其紧邻的观点，统计差异与管理上的重要程度分别解释。

讨论回到综述中采用的研究成果，具体说明一致在哪里、差异在哪里、对象或方法怎样解释差异。与预期不同的发现进入机制分析，并据此调整方案依据；分析过程形成的新解释需用现有证据检视。访谈和业务数据的关系体现在具体结论中，而非两份报告顺次拼接。

结论围绕研究问题归纳实质发现，说明贡献对应的既有基线、实际成果和决策用途，区分发现与由发现形成的建议。摘要、结论和管理成果沿用同一依据与术语；正文以具体研究事实表达适用条件。问题—答案—分析位置的核对索引留在研究底稿，论文用相连论述呈现成果。

## 学术表达自然化与全文去重

全文成稿后、Word定稿前完成一次表达和去重复核，直接修订主稿，再核对受影响的数字、术语、引用、图表说明、摘要与结论。去AI化表达以准确、具体、自然的学术论述为目标，保持正式语体和稳定术语，句式随论证自然展开。

| 表达问题 | 实际修订动作 |
|---|---|
| 宏大背景和泛化意义 | 回到有来源的变化、本对象的问题及研究将支持的具体决策 |
| “专家认为”“研究表明”等模糊归因 | 明确实际作者或机构、所支持观点及对应引用 |
| 密集“首先/其次/此外/综上所述” | 按事实、比较、因果或转折关系连接段落，保留有实际顺序的衔接 |
| 每段同样排比、开头及结尾 | 按内容合并或重组，分别展开发现、解释和管理判断 |
| 宣传性形容、空泛贡献和套话 | 用实际分析、机制及管理成果替换，贡献回到其已有依据 |
| 对话式回应、提示词及编辑指令 | 清理主稿中的协作痕迹，编辑动作进入独立说明 |

以学术含义判断修订效果。证据薄弱的泛化判断先补分析或收敛表述；标点、规范定义和必要连接词按实际语境保留。英文摘要按同一事实和推断强度自然表达，避免中文直译形成机械长句。

通读摘要、各节开头和结论，检查主线是否持续呈现本研究的做法、发现及贡献。若段落频繁转为“无法分析什么”“没有验证什么”，按 [正式论文写法](manuscript-and-supplement.md#方法与来源的学术写法)集中必要研究条件，再将主段改成对实际结果的解释。对真实主要反向或不显著结果仍完整展开。

全文去重同时处理三个范围：

1. **同章重复**：完整/近似段落、换词重述、图表逐行复述和多次介绍相同概念，合并到最能承担论证的位置。
2. **跨章重复**：背景、综述、理论介绍、原因与方案重复铺写时，保留各章新增的分析职能，必要处简要回指。摘要与结论对核心发现的概括、标准定义和专名属于合理复现，核对一致性后保留。
3. **可访问来源重合**：逐段核对过近转述、引语和归属，结合原文核对重要语义重合。用本研究的问题与证据重新组织解释，引用仍对应原观点；确需直接引语时规范标注。

重复扫描先定位，再逐项保留、合并、重写或规范引用；修订后复查受影响内容。保持研究信息和推理完整，学术术语统一使用，不用机械同义词循环。处理记录在qa.repetition与qa.academic_style中写明实际覆盖版本、主要位置及处理结果。

去重后按学校口径复核篇幅与分析展开程度，保持方法、核心证据、解释链和结论齐备。需要充实的部分补入有依据的比较、机制分析或方案取舍，保留必要概括与章节衔接。

## 重复扫描与正式报告回流

需要脚本辅助定位重复时，按 [工具指南](installation-and-tools.md#文本重复扫描)扫描当前成稿，再结合语义及原文审读处理命中。正式查重报告按平台、日期、稿件版本及匹配来源登记，逐项规范引语、补引或重组实际分析，修订后核对原意与数字。检查结果保存在项目文件，正文承载修订后的研究论述。

## 六类质量检查

1. 研究：所有问题有实际答案及正文定位，文献形成的框架参与分析，概念/指标与方法相配，结果、讨论和贡献有对应依据；按全国两类量表审读。
2. 证据：来源准入、引用语义、材料范围、实测/情景与推断强度相符。
3. 数字与图表：原始—清洗—公式—输出可追溯，合计/比例/单位/期间正确，正文、摘要、图表、结论一致。
4. 引用：最新现行国标已复核，全文统一体例、题录与正文双向闭环、图表/脚注/附录覆盖。
5. 原创表达：内部重复与可见来源近似检查、语义审读、术语/对象一致；有正式报告时完成反馈。
6. Word：样式与分节、封面题名页/声明适用、页眉页码、更新目录题注、续表表头、图文布局与全部页面视觉检查。

使用 [项目记录](project-schema.md)核对问题、答案、论断、图表及证据；配合 [工具指南](installation-and-tools.md)定位结构和引用问题。实质审读回到当前正文、原始材料和分析过程，完成返修后保存本稿对应的结果。

## 版本与完成标准

研究稿的补证任务和导师审阅的关键事项写入独立补充说明，正文提供可审读的连续论证并据实说明方法与数据来源。送审候选稿需实际完成相关研究、补充任务和检查，格式与当期提交要求协调。project.json记录实际报告和定位。

续写或导师修改后先比对本次稿件和上次检查覆盖的版本。核心数字更正需连带检查正文、表格、摘要及结论；增删内容需复查目录、引用编号和实际分页。按 [项目记录](project-schema.md) 登记可选内容版本及QA版本，受影响检查重新执行，未受影响检查先说明依据再沿用。

匿名/归档版本、域更新及全部页面的实际验收按 [Word定稿](word-and-tables.md#全文定稿与逐页验收)执行，检查记录对应当前稿件。

完整论文交付正文DOCX、实际使用的证据/引用索引、必要计算底稿及精简QA；避免把工具测试数据、提示词和大量内部日志塞进论文。小任务交付其成果，不擅自扩大为全篇改写。
