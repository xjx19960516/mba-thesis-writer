# Word与数据图表

使用已核验数据生成原生Word表格，文本/数字可编辑。复杂图可用矢量或高分辨率图像，保存分析与源文件。插图不替代应可编辑的数值表。

先确定表格回答的研究问题、列/单位/期间、数据来源、需要比较的关系和正文可得结论。根据需要使用描述、比较、趋势、诊断、调查、回归、访谈编码/时间线、问题措施对应、责任计划和KPI表。方案表可标“建议/预期”，实证表必须取实际数据。

各列数字精度、百分号和缺失符号统一；缺失用“—”等并释义，不填零。比例显示与分母相连，合计差异可能由舍入造成时在注说明。原始数据清洗与运算在分析程序中完成，表格工具仅渲染已核验输入，不暗中生成数据。

## 表格生成工具

`scripts/build_table.py` 需要Python 3.10+与python-docx；其他审计脚本只需Python标准库。默认加载技能自己的 `assets/ustc-format.json`，支持 `--profile` 使用本项目等结构配置，不依赖其他Skill目录。

输入JSON字段：`number` 如3.1、`title`、`headers`（非空字符串数组）、`rows`（相同列数的字符串/数字/null）、`source`（具体数据/资料来源）；可选 `note`、`column_widths_cm`、`alignments`（left/center/right）、`border_style`（three_line/grid/none）、`continuation`（布尔）、`new_page`（布尔）。三线式是技能默认排版选择，不是模板强制。

```text
python "<技能目录>/scripts/build_table.py" "<项目目录>/table.json" --out "<项目目录>/table-fragment.docx"
python "<技能目录>/scripts/build_table.py" "<项目目录>/table.json" --input "<项目目录>/thesis-working.docx" --anchor "【插入表3.1】" --section 1 --out "<项目目录>/thesis-with-table.docx"
```

`--input`模式需唯一的顶层整段锚点且不含分节符；`--section`是锚点所在的1起算分节，用该节正文宽度校验列宽。脚本拒绝输入输出相同、既有输出文件、重复/缺失锚点和越界列宽。先在工作副本保留锚点，工具替换该段为表题/表/注，不修改其他文本。更新正文首次引用和图表登记由写作流程完成。

独立表格片段不是完整论文，不含完整封面、声明或正文。脚本显式设置11pt字体、单倍、段前后3pt、表上题/下方注、表头重复及列宽。需要超长内容/合并多级表头可由文档工具扩展，保留同样格式约束。

所有命令中的占位目录须替换为实际绝对路径，运行约定见 [安装说明](../README.md)。表格默认左右内边距各0.15cm以分隔相邻列，可用格式配置的 `table.cell_padding_cm` 调整；这是可读性默认值，不是学校硬性条款。

插入使用独立表格文字样式并显式关闭非要求的斜体、下划线和段前分页，避免原稿Normal样式改变表格外观；宿主原有样式和正文保持不变。表题编号是实际可编辑文本，插表后仍需写作流程管理SEQ/REF字段、编号变化与正文引用，不能把文本题号误称自动编号。

## 跨页与宽表

Word重复表头不等于续表题。渲染后确定断点，必要时拆成连续两个原生表，后块用 `continuation: true, new_page: true` 生成“续表X.X”，重复表头，最后一块放总表注。每次内容变更后重新检查实际分页，不以固定行数断页猜测最终版。

宽表依次精简表头、按语义换行、重分列宽、拆分不同信息或移附录。若学校允许，可设专门横向节并复核页眉页码；不通过把字体缩小到规定以下来塞满。特别长的单行不能仅依赖“禁止跨页断行”，应拆成可读记录或改变结构。

按模板保持正文先提及、图表就近、题注与对象相连、上下间隔；不要把全部行keep-with-next导致整表跳页。caption/表头需要相连，普通数据行按内容安排。自动题注、交叉引用和目录更新应在Word/可用域更新工具执行后核对显示值，不能只留域代码。

按 [中科大格式](ustc-format.md) 修复模板预设样式冲突。`audit_docx.py`只检查结构、显式参数和模板残留线索，不计算真实分页，也不证明继承后的全部字体正确。排版最终由渲染逐页审查完成。
