# 研究设计与开题继承

## 模式与继承

开题基线保存原文件定位，逐项连接开题任务、已有材料、待补证据、方法、正式论文落点和实际成果。计划不证明访谈、问卷或试点已经实施。修订时建立“意见—原位置—处理—新位置—依据”；润色不自行改变数字和结论。只有题目时先评估研究边界、管理问题与证据可得性，只有方向时再推荐差异化选题，不要求用户重复填写相同长问卷。

管理领域、论文类型、方法分开：营销是领域，专题/案例是体例，问卷是方法；数字化不自动意味着技术建模。专题研究形成问题—成因—方案闭环；描述型案例形成真实事件—解释机制—竞争解释—适用条件—实践总结；决策型案例围绕真实困境、决策选项和解决路径展开。

## 领域适配示例

| 情境 | 可研究问题 | 数据与实践成果 |
|---|---|---|
| 营销/销售/客户 | 获客、转化、留存或渠道配置 | CRM队列、订单与访谈；资源分配与服务机制 |
| 战略/国际商务 | 业务选择、进入路径、能力匹配 | 经营与竞争证据、真实决策；战略备选比较 |
| 财务/会计/风险 | 资金周转、成本驱动、控制有效性 | 同口径财务和流程资料；控制/决策方案 |
| 人力/组织 | 激励、流动、协同和领导过程 | 实际量表、档案和访谈；机制设计 |
| 运营/项目/供应链 | 周期、质量、履约、库存与资源约束 | 工单、台账和事件；流程或排程改进 |
| 信息系统/AI管理 | 采用、协同、治理和绩效 | 使用与业务数据、组织证据；实施/治理路径 |
| 创新/创业/ESG/治理 | 学习、决策权、利益相关者治理 | 事件、制度与披露；评价或实践总结 |

这些是路由示例，不限制领域或固定理论。选能解释核心关系的理论，明确构念与可观察证据；工具只服务具体诊断与选择。二三级标题体现业务环节或研究机制，不只是替换企业名称。

## 从文献形成研究框架

文献综述结束时，将主要共识、争议及情境差异收敛为本研究的分析框架。围绕核心问题说明采用哪些概念与关系、为何适用于本对象、哪些内容需要情境调整，以及将用何种证据分析。相互冲突的文献结论，结合其研究对象、测量与设计解释采用依据。

用简表、机制图或连续论述形成“文献依据—采用或调整理由—本研究机制—可观察证据—分析位置”的对应关系。框架用于后文诊断、解释、方案或案例比较；写作完成后，回查核心关系是否在实际分析中得到回应。探索性研究可形成分析命题或主题，不必统一改写成统计假设。

## 关键概念与操作化

对参与核心分析的概念，在分析底稿中建立以下对应关系，正文方法部分提炼影响结果理解的内容：

| 项目 | 需要确定的内容 |
|---|---|
| 定义与层次 | 采用的概念定义，分析的是个人、客户、团队、企业或事件 |
| 对象与期间 | 观察对象、纳入规则、研究期间及时间窗口 |
| 可观察依据 | 业务字段、量表题项、事件证据或定性编码定义 |
| 计算或编码 | 分母、单位、计分、聚合规则或主题归类依据 |
| 来源与用途 | 材料定位、回答哪个问题、进入哪项比较或解释 |

例如客户留存需定义客户身份、基期客户集合及复购窗口，满意度采用相应测量，忠诚度按所用定义取得证据；三者在分析中保持各自含义。跨期比较检查客户队列和观察窗口是否可比，近期队列尚未经历完整窗口时采用适合的观察处理。从个体材料形成团队或企业判断时说明聚合与推断依据，访谈主题与业务指标通过共同问题连接。

这些内容可保存在现有项目记录或分析底稿中，按实际方法取舍；不增加无关构念、空表或统一指标清单。

## 方法选择与质量条件

涉及问卷设计、已有问卷但无数据、真实答卷或模拟演示时，按 [问卷与模拟分析](questionnaire-and-simulation.md)执行，区分工具设计、真实调查和模拟结果。

| 路径 | 实际需要 | 解释与检查 |
|---|---|---|
| 档案/业务数据 | 单位、期间、字段、分母、清洗、缺失/异常规则 | 同口径趋势/结构/队列，录入与选择偏差，结果变化不直接等于成因 |
| 问卷 | 构念/量表来源、调整、样本框、招募与回收记录 | 按测量目的检验适用信效度与模型条件，说明非应答；不强制SEM |
| 访谈/观察 | 真实岗位/对象、日期、选择理由、提纲和记录 | 编码至主题链、负面意见、必要三角核验；主观看法与事实区分；饱和按实际过程说明 |
| 案例/内容分析 | 案例边界、时间线、原始记录、编码/比较规则 | 区分事件叙述、研究者解释和替代解释；不得编造引语或补造事件 |
| 回归/面板/SEM | 数据结构、测量与识别假设、模型规模依据、诊断 | 关联不升级因果；按方法做必要稳健性分析，不按固定样本数一刀切 |
| 预测 | 时点信息、训练/验证划分、基线、可用字段 | 防未来信息泄漏，报告样本外误差和适用范围 |
| 因果评价 | 对照/自然实验等识别设计、时点、混杂与趋势 | 核验识别假设，普通前后对比只作与设计相称的描述 |
| AHP/综合评价/优化 | 真实判断或权重依据、尺度、约束与目标 | 一致性/敏感性与基线比较；演示权重不变成实测 |
| 混合研究 | 各路径材料、整合位置与方式 | 说明如何互相解释、怎样处理冲突，不平行堆结果 |

定量结果报告实际有效样本、估计量、单位、效应大小及适用的不确定性，按方法核对前提、缺失、异常和偏差。定性分析保留记录—编码—主题—论断定位及相反意见，混合研究在具体结论中整合证据。

专题研究按全国定位适度结合定性定量，可靠描述统计/业务指标也可承担量化；不为“高级”强加问卷、访谈数量、模型或显著性。方法所需证据不可得时完成可靠公开/描述分析，提出具体替代设计；改变已通过核心方法需按授权执行。

## 方案与效果

将措施对应已分析的问题或案例发现，交代机制、备选选择理由、责任、资源/预算依据、时间、依赖、执行指标与反馈。方案表中的责任和目标属建议，除非已有正式确认；成本估算保留单价/工时/公式与范围。

比较核心措施与可行备选或维持现状的取舍，检查各措施的资源安排是否相容。预算、收益与工期保留可复算依据，不确定值采用合理情景或敏感性分析。KPI明确公式、单位、基期、数据来源、频次、责任及目标依据。

严格区分：已实施且有过程/结果证据；未实施但完成可复算测算/真实专家评价；仅提出未来试点和评价设计。只有第一类可写实测实施效果。研究局限写对象、期间、资料和方法的具体边界。

贡献对应已完成成果：相较哪项既有解释或管理实践，本文新增了什么判断、工具或机制，由哪些分析支持，改变什么管理决策，适用于哪些情境。应用型论文可以形成对象诊断、机制解释、决策工具或实施体系；理论贡献按实际程度表述。是否设创新专节依学校与类别，不以软件或换企业名构成创新。
