# 全国MBA论文规范基线

依据：用户提供的《工商管理专业学位类别硕士学位论文基本要求（试行）》；通知 MBA委〔2024〕2号，2024-05-08发布，附件封面2023-12。页码按原PDF文件第1–9页计算。内置 [PDF原件](../assets/mba-requirements-2024.pdf) 用于定位复核；本次核验2026-09-09。后续项目核对有无更新及培养单位适用要求。

| 定位 | 要求与适用范围 |
|---|---|
| 3页 | 在导师指导下独立研究，科学严谨，体现管理问题提出、分析、解决与实践能力；保留作者实际研究和复核记录 |
| 4页 | 选题来自真实企业组织管理实践，聚焦明确问题，有解决空间与资料取得条件；本人所在企业是建议，不是唯一允许对象 |
| 4–5页 | 企业材料合规使用与脱敏，保护商业秘密；原始材料与公开输出分开，脱敏保留分析可追溯性 |
| 5页 | 应用研究型专业学位论文，恰当理论工具、系统分析、可操作解决方案或实践总结 |
| 5页 | 主要体例为专题研究、案例研究；其他形式/成果需培养单位明确标准，不把商业计划等当全国统一第三类 |
| 5–7页 | 专题研究定性与定量相结合，形成问题描述—分析—解决；可靠描述统计/业务指标可承担量化，无复杂模型硬门槛 |
| 7–9页 | 案例呈现特定情境下独特真实管理实践，叙述与理论分析相连，资料真实、客观、充分 |
| 8页 | 可以脱敏名称和敏感数据，管理事件、困境、决策须真实发生；一手深入调研是提倡，并非排除充分公开资料 |
| 8–9页 | 描述/平台型重在解释为什么及内在机制；问题/决策型重在成因与如何解决 |
| 9页表2 | 分析结果可为可信方案，或管理概念/理论/模型的可靠总结，不强制所有案例完成同一种对策目录 |

## 类型质量复核

专题研究对照7页表1：选题管理意义、问题真实与清晰、理论工具恰当、成因系统分析且证据充实、方案及可行性、引用与结构/语言/版面规范。

案例研究对照9页表2：选题意义、案例正文聚焦且真实充分、明确而恰当的理论工具、资料与理论紧密结合、可信方案或可靠总结、写作规范。逐项记录论文位置和证据，作为审读维度；不虚构评分权重和合格分数。

文件中“一般来说”的内容模块属于组织参考，不规定固定章数/顺序；“建议”与“提倡”保留其强度。该文件未规定论文字数、外文/近年文献比例、篇数、查重率、AI检测率、字体页边距、三线表或引用国标版本，不能把这些归为全国MBA硬性条件。
