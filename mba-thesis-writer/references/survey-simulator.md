# 可复算的问卷演示工具

`scripts/simulate_survey.py`用Python3.10+标准库生成临时演示记录、描述统计和报告。它按照明确的选项人数配置生成数据，支持单选、连续整数Likert评分、反向计分及按前题分组设置人数。不支持真实调查采集、多选、跳转、缺失机制、指定相关矩阵、信效度或显著性目标；这些需另行设计适用方法，不能把当前工具输出视为已经满足。

## 使用

复制并修改 [示例配置](../assets/survey-simulation-example.json)，保存在项目目录。示例中的12条记录和两个情景仅用于演示；不作为论文样本量建议。

```text
python "<技能目录>/scripts/simulate_survey.py" "<项目目录>/simulation-spec.json" --out-dir "<项目目录>/simulation-v1"
```

输出目录的父目录须存在，输出目录本身须为新目录；工具拒绝覆盖已有目录，不修改配置原件。先完成配置验证和全部内容计算，再创建输出。磁盘等写入错误可能留下不完整新目录，应保留检查并选择新目录重试，不把部分文件当完整结果。成功返回0及`simulated_generated`，输入或输出错误返回2。工具不联网，不上传数据。

## 配置协议

- 根字段：`data_origin`固定为`SIMULATED`，`purpose`说明用途和生成假设，`sample_size`为生成记录数，`seed`为整数随机种子，`questions`按生成顺序排列。
- 题目字段：`id`为不重复的英文字母开头变量名，`text`为题目，`kind`为`single`或`likert`，`options`按问卷选项顺序填写`value`与`label`。单选编码为字母或数字开头的字母数字/下划线/连字符字符串；Likert为连续整数编码。`reverse`可选，仅用于Likert计分；原始编码不改变，报告同时提供原始均值和计分均值。
- 整体人数：`counts`与选项一一对应，非负整数之和必须等于生成记录数。
- 分组人数：以`condition_on`引用前面已生成的题目，用`counts_by_group`代替`counts`。字典键是前题每个选项编码的字符串，必须完整覆盖；各组人数之和必须与该组实际生成记录数一致，空组也需填全零配额。

同一题不能同时指定整体和分组配额。先把百分比转成可解释的整数人数并记录舍入方法，再生成；不可能同时满足的要求应修正或明确取舍。暂不支持的字段会报错，不默默忽略目标。工具运行上限是10万记录、200题、总计200万答题单元，属于资源保护范围，不是研究方法或有效样本建议。

给定记录数和选项人数后，工具依题目顺序在各组内随机分配。相同配置、工具和Python环境可重复生成；跨Python版本比较时核对输出，保留环境版本。分组差异来自配额设计，不构成现实结论的验证。未约束的跨题关系可能偶然变化，不承诺量表信度、回归系数或显著性。

## 输出及检查

| 文件 | 用途 |
|---|---|
| simulated-responses.csv | 带SIM记录ID及SIMULATED来源列的逐条生成数据，UTF-8 BOM便于表格工具读取 |
| simulation-spec.json | 生成配置及题项编码标签，相当于本次演示代码本 |
| simulated-summary.json | 从实际生成行重算总体/分组人数、比例与适用均值；空组的比例和均值为null |
| simulated-report.md | 题目、分组描述表、数据性质与解释范围，便于按论文模板继续排版 |
| provenance.json | Python版本、生成器哈希及上述文件SHA256，用于复现与完整性核对 |

校验逐条记录与汇总表相符，分组均值及方向符合已声明假设。只有描述统计经过程序计算，不把报告标题或文件生成成功理解为真实调查验证。报告扩写和Word表格由Agent继续完成，并保留演示来源。使用 [表格工具](word-and-tables.md)导出时，将模拟来源文字传入`source`，不改为“问卷调查所得”。

用户要求先写全文后补真实结果时，按 [临时结果工作稿](temporary-results-workflow.md)在独立说明中登记替换位置和任务。Agent依据工具实际生成的结果继续完成报告解释、Word装配和正文更新，按实际取证情况记录研究进度。
