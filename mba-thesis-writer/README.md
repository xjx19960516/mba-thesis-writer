# MBA Thesis Writer｜MBA论文研究与写作

独立发布基线：**1.3.3** · 2026-09-11

面向MBA专业学位论文的研究、分析、写作和Word交付技能。从论文题目、已通过开题、已有草稿或导师意见启动，根据真实管理问题安排理论、方法、取证与章节，持续推进到完整论文及配套研究材料。以完整、严谨、可审读和可复核的成果为目标，正文采用正式学术表达，编辑与材料补充事项集中放入独立说明。

本包以普通Markdown为指令入口，附带规范、模板、工作流程和可选Python工具。无需历史对话、其他论文技能、特定模型或连接器。支持读取文件的agent/harness可按相对链接使用全部资源；自动安装和工具执行方式由所在环境提供。

## 能完成什么

| 工作 | 执行内容与成果 |
|---|---|
| 研究设计 | 明确管理问题、研究目标、推断目标、理论与数据路径，形成有证据落点的章节安排 |
| 开题转正式论文 | 继承已通过的开题基线，完成取证、研究深化与成果形成，记录实质调整 |
| 主动联网取证 | 检索官方资料、学术文献、统计及企业公开信息，核对出处、口径、时间、适用性和第三方质量 |
| 文献与引用 | 核验题录及实际支持内容，形成主题综述、论断关联和正文—文后双向核对 |
| 调查工具与分析 | 设计问卷、访谈提纲、编码和实施方案，清洗真实记录并选择适合研究问题的分析方法 |
| 情景与演示分析 | 用明确参数生成可复算的问卷演示记录、描述统计和分析报告，支持研究结构试验及后续实测更新 |
| 管理诊断与方案 | 将问题证据连接到机制解释、可行备选、实施责任、资源、进度和评价指标 |
| 图表与Word | 按论证需要生成可编辑表格，核对来源、单位、题注、正文引用及学校样式，装配完整DOCX |
| 全文修订 | 处理导师意见、跨章矛盾、数字不一致、重复论述和空泛表达，同步摘要、结论和附录 |
| 交付复核 | 结合来源审读、可复算分析、成稿引用核对及逐页版式检查，输出主稿和简明验证记录 |

适用领域包括营销与客户管理、战略、财务会计、人力与组织、运营与项目、供应链、数字化、创新创业、治理及ESG等。专题研究和案例研究按管理问题选择适合的结构，理论、模型、章数和统计复杂度由研究需要决定。

## 从哪些材料启动

| 启动材料 | 默认工作 |
|---|---|
| 题目或方向 | 结合对象、数据条件和学校要求建立可执行研究设计 |
| 已通过开题报告 | 提取已确认内容，安排正式研究并连续完成全文 |
| 论文草稿及导师意见 | 定位意见，复核论证与证据，修改关联章节和图表 |
| 完整稿及模板 | 核对引用、表达、全文一致性、Word版式与交付要求 |

已有资料尽量一次提供：学校/学院与当期模板、题目和开题、研究对象与期间、企业或公开资料、调查工具与实际数据、导师意见、交付要求。Agent先提取文件中的信息，集中处理影响研究设计的必要问题，其余已具备条件的工作持续进行。

## 完整论文怎样完成

1. **建立研究基线**：确定核心问题、成果、适用规范和证据路径，将章节与研究问题对应。
2. **取得并核验材料**：自主补充可靠公开证据，建立来源与论断记录，准备必要调查工具。
3. **完成分析**：保留清洗与计算过程，形成问题判断、原因解释、替代解释及管理含义。
4. **形成实践成果**：比较可行措施，明确责任、资源、进度、依赖关系和评价设计。
5. **连续写齐全文**：先完成分析与方案，再校准绪论、综述、摘要和结论，整合必要附录。
6. **内部审读与返修**：检查研究问题是否回答、证据是否支撑、数字引用是否一致，并修复发现的问题。
7. **Word交付**：应用学校模板，更新目录与字段，渲染并逐页核对，保存最终文件与实际检查记录。

一次完整论文委托默认推进全部适用章节，长任务分批保存并接续，不以提纲、片段或仅有标题的章节结项。详见 [全文执行流程](references/full-thesis-workflow.md)和 [成品交付要求](references/delivery-contract.md)。

## 正文与补充材料怎样交付

论文正文完整展开问题、证据、分析、方案和结论，图表有说明，引用有对应，适用的前后置内容和附录齐备。正文清理“此处补充”“后续整理”“尚未完成”等编辑指令，以实际研究内容形成连贯论证。

需要用户材料或真实调查更新时，另交付《论文补充材料与修订说明》，逐项写明所需内容、章/节与段落锚点、图表编号、取得与计算步骤、关联摘要/结论和验收条件。可以自主检索、计算或修改的问题先完成处理，独立说明只保留实质事项，并记录当前材料性质、来源和分析依据。泛化自评先转为可处理问题，按 [内容分配规则](references/manuscript-and-supplement.md)执行。数据来源、研究方法与影响解释的条件仍在论文相应位置正常表述。

问卷按研究问题、理论构念和测量要求设计；预期结论作为待检验假设。缺少答卷时可交付完整问卷、实施方案和按明确假设生成的情景分析报告。生成数据在方法及图表来源中说明性质，独立说明列出真实答卷取得后的重算和修订位置；实际回收与分析结果决定经验结论。详见 [问卷设计与分析](references/questionnaire-and-simulation.md)、[先成稿再更新](references/temporary-results-workflow.md)及 [正文与独立说明](references/manuscript-and-supplement.md)。

| 文件 | 内容 |
|---|---|
| 完整论文.docx | 中英文题名与摘要、关键词、全部正文、参考文献及模板适用内容；图表可编辑 |
| 研究附件 | 实际使用的来源记录、调查工具、清洗/计算材料与必要数据字典；按研究需要整理 |
| 质检说明 | 对应稿件版本、检查内容、实际覆盖页码及验证结果 |
| 论文补充材料与修订说明.docx | 有实质补充事项时单独提供，准确定位取得、替换和关联修改动作 |

送审候选稿以研究证据、全文和实际复核全部完成为依据；含临时待替换调查结果的文件作为完整研究工作稿交付。文件状态写在文件名与交付说明中，正文保持正式论述。

## 规范与模板

- **全国MBA要求**：随包保留用户提供的2024年MBA论文基本要求，研究定位和类型说明见 [全国要求](references/national-requirements.md)。
- **中国国家引用标准**：本版记录的核验基线为GB/T 7714-2025，实施日2026-07-01，核验日2026-09-10。每篇论文启动与定稿重新检查官方状态及适用规则，记录见 [baseline.json](baseline.json)；执行见 [证据与引用](references/evidence-and-citations.md)。
- **学校格式**：内置中国科学技术大学模板及参数，具体取值和差异见 [中科大格式说明](references/ustc-format.md)。其他学校优先使用其当期模板，研究流程和工具继续使用，学校专属封面与参数按实际对象调整。

模板是格式与规范资源，其中示例文字不作为研究事实。内置文档保留原发布方的适用范围；本包不包含用户企业研究资料或真实答卷。仓库尚未单独指定统一开源许可证，随包第三方资料沿用其发布方的使用条件。

## 安装与首次调用

从 [项目仓库](https://github.com/xjx19960516/mba-thesis-writer)获取完整目录或指定版本安装包。解压后定位同时包含`SKILL.md`、`baseline.json`和`manifest.json`的目录，保留全部资源及隐藏文件。支持技能发现时按该环境机制安装；其他环境将完整目录放入可读工作区，直接读取入口执行。

可把以下文字交给AI：

> 请从 https://github.com/xjx19960516/mba-thesis-writer 下载mba-thesis-writer完整技能，按实际baseline.json确认版本；指定版本时核对相应安装包及SHA256。保留整个技能目录和隐藏文件，先读README.md与SKILL.md。按当前环境的技能机制加载，或放入可读工作区直接执行。保留已有本地修改；有Python时运行scripts/doctor.py --self-test，报告实际版本、位置和自检结果。论文资料与输出放在独立项目目录。我的任务是：【论文任务】；资料目录：【目录】。

详细路径、依赖、工具命令和环境适配见 [安装与工具指南](references/installation-and-tools.md)。`agents/openai.yaml`是可选界面元数据，核心规则使用普通文件。仅复制入口文件会遗漏规范、模板及流程，应安装整个目录。

## 使用示例

**从开题完成论文**

> 请使用mba-thesis-writer，读取项目目录中的已通过开题、学校模板及研究材料，继承研究基线，补充并核验公开证据，完成分析、全部章节、图表、引用和Word排版。连续推进全文并内部返修，交付完整DOCX、研究附件和质检说明；确需补充的材料另出文档，标明准确位置与处理方法。

**按导师意见优化全文**

> 请使用mba-thesis-writer，将导师意见逐项对应到论文位置，复核证据、逻辑和方案可行性，完成关联章节、图表和中英文摘要的同步修改。按学校模板交付完整修订稿及精简修改说明。

**设计问卷并准备分析**

> 请使用mba-thesis-writer，依据研究问题和理论构念设计完整问卷、变量编码、抽样与回收方案；已有真实答卷时完成清洗和分析。需要演示时用明确假设生成可复算数据与报告，并在方法中说明性质。真实答卷到达后的重算、替换和关联修订位置单列说明。

## 版本变化与验证

1.3.3在1.3.2完整发布说明与成品要求的基础上，统一正文和额外文档的内容分配，补充简洁方法写法与准确替换示例，扩充独立说明的当前依据字段，并协调证据与问卷流程中的生成数据用途。七个Python工具、研究记录结构和学校模板参数延续前版。

发行验证包含工具回归、自检、入口格式、相对链接、单根目录安装包和SHA256一致性。具体执行结果见随发行提供的复核报告。基线实测Python 3.12、python-docx 1.2.0及Windows；已有Word样例排版验证覆盖代表性表格，完整论文按项目稿件另行逐页检查。Linux/macOS及各agent/harness的自动发现机制以目标环境自检为准。
